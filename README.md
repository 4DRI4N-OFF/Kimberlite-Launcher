# Kimberlite Launcher

`«<KIMBERLITE>»`

La web de **Kimberlite**, el launcher de Minecraft de Adrián.

> Kimberlite está en desarrollo. Este repositorio contiene su sitio web;
> todavía no hay descarga pública del launcher.

## Qué es Kimberlite

Un launcher de Minecraft personal. Su seña de identidad es la ventana:
cristal estilo iOS 26 y una intro en la que `«<>»` se abre hasta
`«<KIMBERLITE>»`.

## Este repositorio

Sitio estático, sin frameworks ni paso de build:

| Archivo | Contenido |
| --- | --- |
| `index.html` | Portada, con una ventana de muestra interactiva (Jugar, Instancias, Mods, Ajustes) |
| `styles.css` | Dirección visual: base piedra de cantera, cristal claro estilo iOS 26, listas con separadores finos |
| `app.js` | JavaScript sin dependencias: pestañas, secuencia de Jugar, interruptor de reducir animaciones, reveals al hacer scroll |
| `LICENSE` | MIT |

La web se publica con GitHub Pages desde `main`.
